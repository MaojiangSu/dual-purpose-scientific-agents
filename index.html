Abstract

Experimental feedback serves two purposes in scientific design: benchmarking scientific agents and providing verified evidence for subsequent learning. Under a limited experimental query budget, the items most useful for distinguishing agents may not be those most useful for improving them. We study dual-purpose experimental design, where each agent performs multiple runs on the same scientific item and acquired measurements support both outputs. Our adaptive strategy estimates benchmarking and learning sample values separately, then selects which item to verify next. A lightweight learning operator updates external experimental memory while keeping the language model frozen. On held-out GB1 variant pairs, the memory improves the target agent's accuracy from 63.3% to 69.5%. At a matched 384-item budget, Adaptive Joint reaches 70.12% versus 69.27% for Random, but has higher benchmark mean-score error. The results support experimental-memory learning and identify a limitation of the current acquisition estimator.

Why One Budget Has Two Objectives

A protein-variant pair is easy to ask about and costly to verify. Once its two fitness values are acquired, every cached agent answer can be scored, and the same evidence can improve the target's next decisions.

Adaptive Item Selection

Each item contains public context and two candidate variants. Verification reveals both fitness measurements. The method alternates item selection with small-batch memory updates.

  1. Cache Multiple Runs Of Fixed Agents

    Collect label-blind reference answers before revealing assay results. Repeated runs capture variability of the same agent on the same item.

  2. Estimate Two Sample Values

    Predict the set-level benchmarking marginal from outcome probabilities. Estimate learning potential from actual batch-level update feedback and the current memory state.

  3. Verify The Next Affordable Item

    Combine the normalized values with a fixed preference and optional exploration. Pay the declared query cost and reuse the acquired measurements for both purposes.

  4. Update Memory Through A Validation Gate

    Fit residue-pattern interactions from acquired evidence. Retain a candidate only when its complete decision rule improves development performance; keep acquired evidence even when an update is rejected.

Learning Feedback Without Per-Item LLM Editing

The fallback prompt stays fixed. A cached development response bank can therefore evaluate new experimental memories using CPU inference. Each batch produces one signed update gain and one accepted gain, rather than duplicated labels for all its items.

What The Analysis Establishes

The analysis explains the quantities used for selection and the evidence needed to interpret them.

Multiple Runs Expose Noise

For a fixed evaluation set independent of its response bank, finite-run variability contributes to observed between-agent separation. A numerator correction does not make the full SNR ratio unbiased.

Singleton SNR Can Be Uninformative

With valid binary answers, flipping the experimental winner complements all scores and preserves single-item SNR. The set-level marginal retains interaction with earlier verified items.

Selection And Reliability Differ

Sample values are bounded, but can be negative. Budget checks guarantee feasible expenditure. Benchmark accuracy and held-out learning gain require independent measurement.

What This Establishes

Experimental memory can improve this frozen agent. The present acquisition estimator does not establish a better joint trade-off: Random has the lowest benchmark MSE, and every learning-prediction MSE ratio is above one. The complete allocation stage costs $12.58 in usage-priced API calls.

Repeated runs of an agent estimate execution variability. Allocation seeds repeat item selection. Neither creates independent protein replicates. The component result above is reported separately from the allocation protocol.
