Dual-Purpose Experimental Design for Benchmarking and Improving Scientific Agents

Maojiang SuHan Liu

Center for Foundation Models and Generative AI
Northwestern University

AbstractOverviewProblem SetupMethodExperiments

Across adaptive rounds, we choose which protein comparisons to verify next using earlier experimental feedback. The same verified results both score scientific agents and teach a target agent through external experimental memory.

Abstract

Experimental feedback serves two purposes in scientific design: benchmarking scientific agents and providing verified evidence for subsequent learning. However, under a limited experimental query budget, the items most useful for distinguishing agents may not be those most useful for improving them. To address this trade-off, we study dual-purpose experimental design, where the same acquired experimental feedback supports both agent benchmarking and subsequent improvement. We propose an adaptive sampling strategy that balances benchmarking and learning through separate sample-value estimates. At each adaptive round, the strategy uses experimental outcomes from earlier rounds to update its value estimates and select the next item to verify. We analyze finite-run variability, the outcome dependence of benchmarking values, and the distinction between a selection proxy and benchmark reliability. We evaluate a lightweight learning operator that updates external experimental memory while keeping the underlying language model frozen. On held-out GB1 variant pairs, this memory improves the target agent's accuracy from 63.3% to 69.5%. In a two-agent comparison at a matched 384-item budget, Adaptive Joint achieves 3.88 times Random's construction-bank SNR and 70.12% held-out accuracy versus 69.27%. Static Joint remains higher on both mean objectives, and independent benchmark mean-score error is worse for Adaptive Joint. These results support fixed-bank dual-purpose gains over Random while leaving the adaptive advantage and benchmark fidelity unresolved.

The Adaptive Experimental Design Loop

Our algorithm uses earlier feedback to estimate two values and choose the next item. The same verified outcome supports benchmarking and agent improvement.

Motivation

Experimental ground truth supports two scientific uses: comparing agents and improving a target agent. Both depend on verified outcomes, and both compete for a limited experimental query budget.

A task that clearly separates competing agents may provide little new evidence for learning. A useful training item may contribute little to benchmark discrimination. We therefore choose which items to verify by treating benchmarking and learning as two objectives that evolve with the acquired feedback.

Problem Setup

We start with a pool of scientific items whose experimental outcomes are hidden. A policy selects items sequentially under one query budget; each acquired outcome supports both the fixed reference panel and an improving target.

Scientific Items
Each item has public context, an unknown experimental outcome and a declared query cost. In the protein setting, one item is a pair of variants; verification reveals two fitness values and costs two measurements.
Adaptive Decision Rounds
One round selects and verifies one item. After the common warm-up, the next choice depends on outcomes from earlier rounds and the retained memory. Memory changes only when a batch update passes evaluation on the validation set.
Reference Agents And Repeated Runs
A fixed panel of agents answers each item independently several times before verification. Cached answers become benchmark scores only after the experimental outcome is acquired. Multi-runs measure variability within the same agent.
The Improving Target
A separate target agent changes its external experimental memory as evidence accumulates. Its base language model and fallback prompt remain fixed, as does the reference panel.

Two Objectives Under The Same Budget

1. Benchmarking

Build a verified set that separates reference-agent mean scores relative to their run-to-run variation. The paper uses a set-level signal-to-noise ratio, denoted by F.

The initial round gives the full-budget problem. Later rounds condition on newly acquired feedback while keeping the same terminal benchmarking and learning goals. Warm-up queries count toward the budget.

Selection Across Adaptive Rounds

Each decision round chooses and verifies one item using feedback from earlier rounds. Benchmark values refresh after each query; memory updates and new learning-gain observations occur at batch boundaries.

  1. Warm Up

    Query a shared random set to initialize the outcome predictor, experimental memory and batch-level learning feedback.

  2. Select Using Earlier Feedback

    Predict the benchmarking marginal and learning potential of each remaining item. Combine normalized values and exploration bonuses per unit cost, then select an affordable item.

  3. Verify Once, Reuse Twice

    Pay the query cost and reveal the outcome. Score all cached reference runs, add the measurements to training evidence, and refresh the benchmarking predictor.

  4. Update Memory At Batch Boundaries

    After a small batch, fit a candidate memory and retain it only if validation performance improves. Record both proposed and accepted gains to update the learning predictor, then continue until the budget is exhausted.

Value Estimation

The benchmarking predictor combines exact sample values under possible outcomes with estimated outcome probabilities. The learning predictor uses item and memory features together with earlier batch-update gains. These working estimates are updated as verified data arrive.

The validation set selects memory updates; the held-out set evaluates generalization. An accepted update does not guarantee held-out improvement.

Experimental Results

We first test whether verified feedback improves the target agent, then compare benchmark construction and learning under the same query budget.

EXPERIMENT 1 · Harness Improvement

This separate harness study tests Terra with experimental memory on GB1. A fitness predictor is trained from acquired measurements. A fixed routing rule consults this memory when its preference is strong; otherwise it keeps Terra's answer. The LLM weights and fallback prompt stay fixed.

Using the validation set, we selected a memory trained on 256 pairs (routing threshold 0.80) from snapshots using 64, 256 and 1,024 training pairs. The full search acquired 1,024 training pairs. The selected memory was then frozen and evaluated on 256 held-out pairs with two fresh runs per pair.

Experiments 2–4 use a fresh GB1 split with no variants shared with this study and learn memory within each acquisition campaign. This frozen-snapshot result is separate from their round-by-round acquisition curves.

Decision Rounds And Update Batches

Each campaign has 384 item-level decision rounds: 128 warm-up + 256 post-warm-up. In Adaptive Joint, benchmarking values and outcome predictions refresh after each acquired item, so feedback can change the next selection.

The first memory fit occurs at 16 items, followed by a proposal every 8 items. This gives 47 proposal records: 15 during warm-up and 32 afterward. The 256 post-warm-up decisions therefore form 32 update batches of 8 items. Validation gating determines which proposals are accepted.

Repeated agent runs share each item's experimental label. Allocation seeds repeat selection while sharing response banks; they are not independent proteins or assays.

EXPERIMENT 2 · Benchmark Discrimination: Acquisition Process

Adaptive Joint has its largest observed SNR advantage over Random at an intermediate budget, around 160 verified items. The advantage narrows overall as coverage grows: its mean SNR is 7.81 times Random's at 256 items and 3.88 times at 384 items.

At full coverage, every policy would verify the same 512 candidates. With the same fixed reference-run bank and SNR definition, their benchmarks and construction-bank SNR would therefore coincide. The plotted experiments stop at 384 items; full-coverage equality is an implication of the setup.

With ε = 0.02, regularization dominates the SNR denominator. The larger SNR here mainly reflects wider mean score gaps; it does not demonstrate a substantial reduction in run noise.

Construction-bank SNR reuses the runs that informed acquisition. It describes discrimination on this cached bank; future independent-run performance is a separate evaluation. Scores on different selected benchmarks are not direct estimates of intrinsic model capability.

EXPERIMENT 5 · Transfer Diagnostic

A separate feature-memory configuration was tested on 96 pairs from 12 unseen UniProt groups. Original Terra reached 69.79%; the memory version reached 66.67%. That configuration did not improve cross-protein performance.

This is a different memory configuration from the interaction-aware GB1 model. The positive GB1 result concerns new combinations within the same protein.

Theory And Update Details

Analysis Results

Finite-run variability contributes to apparent agent separation. A single valid binary item has the same SNR under either non-tie winner, motivating a set-level marginal. Bounded sample values and feasible query accounting do not imply unbiased benchmark estimates, positive test gain or globally optimal selection.

Memory Update Schedule

The first memory fit uses 16 acquired tasks, followed by a proposal every eight tasks. Candidate memories use acquired outcomes only. Evaluation uses a fixed validation response bank, and no per-task LLM editor call is required.
