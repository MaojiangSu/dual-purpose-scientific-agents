One Result Has Two Uses

1. Benchmark The Agents

After verification, compare every cached A/B answer with the measured winner.

2. Supply Experimental Memory

Both labeled variants become training evidence for the target's external fitness predictor.

This step is shown after the shared warm-up. The real learner first fits at 16 acquired items and then proposes an update every eight. A single verification adds evidence; it does not trigger a new LLM editor call.

In the full algorithm, new assay outcomes refresh benchmarking predictions. After each eight-item batch, a candidate memory is fitted and tested on Development; accepted and rejected update gains train the learning-value predictor.

03 · Measured EvidenceWhat Have We Actually Tested?

We separate two questions: can feedback improve an agent? And does our selection algorithm use the same budget better?

Experiment 1 · Learning Feasibility

Can Verified Protein Feedback Improve A Frozen Agent?

We learned an external GB1 fitness predictor from acquired measurements. A fixed routing rule consults this memory when its preference is strong; otherwise it keeps Terra's answer. The LLM weights and fallback prompt stay fixed.

The selected snapshot uses 256 training pairs. The Development search acquired 1,024 training pairs in total, then froze the memory and routing threshold before testing on 256 held-out pairs with two fresh runs each.

What Worked

Held-out accuracy increased from 63.28% to 69.53%: a gain of 6.25 percentage points on unseen combinations within GB1.

What This Does Not Establish

This confirms a useful external memory in one protein setting. It does not prove that adaptive item selection beats Random.

Experiment 2 · Equal-Budget Selection

Does Adaptive Selection Beat Random?

A new split gives every policy the same candidate pool, updater and query costs. We compare six selection strategies using Terra and Sol as fixed reference agents, with Terra as the improving target.

Learning Result At 384 Items

Adaptive Joint: 70.12%. Random: 69.27%. Static Joint: 70.31%. The adaptive version has a small observed gain over Random, and does not exceed Static Joint.

The Joint Trade-Off Is Not Yet Better

Random estimates agent means more accurately. Adaptive Joint's benchmark MSE is about 21.5 times larger. Its learning-gain predictor also loses to predicting zero gain.

Experiment 3 · Transfer Diagnostic

Does The Memory Transfer Across Proteins?

A separate feature-memory configuration was tested on 96 pairs from 12 unseen UniProt groups. Original Terra reached 69.79%; the memory version reached 66.67%. That configuration did not improve cross-protein performance.

This is a different memory configuration from the interaction-aware GB1 model. The positive GB1 result concerns new combinations within the same protein.

04 · The Next ExperimentsWhat Needs To Be Tested Next?

More scale will be useful after we understand the current estimator failures. The next tests focus on the following questions.

  1. Can We Predict Which Feedback Helps Learning?

    Replay saved batches. Compare predicted gain with measured signed and accepted gain, alongside zero and past-mean baselines. The present predictor has only 47 batch records per campaign and sparse accepted updates.

  2. Are We Selecting For The Benchmark We Want?

    Plot discrimination score and independent mean-score error together. Maximizing set-SNR need not minimize mean-estimation MSE; this objective mismatch must be resolved before claiming benchmark accuracy gains.

  3. Does The Same Memory Help Qwen Agents?

    Run matched Qwen3.5-9B and Qwen3.5-35B-A3B tests with the frozen memory and input protocol. Separate baseline ability, memory benefit and inference cost before expanding the reference panel.

  4. Does The Revised Allocator Generalize?

    Freeze the updater, predictors and evaluation target, then compare Random, Static and Adaptive selection on a new variant-disjoint split. Report both learning accuracy and benchmark fidelity at the prespecified budget.

Technical Details, Equations And Full Abstract

Abstract

Experimental feedback serves two purposes in scientific design: benchmarking scientific agents and providing verified evidence for subsequent learning. Under a limited experimental query budget, the items most useful for distinguishing agents may not be those most useful for improving them. We study dual-purpose experimental design, where each agent performs multiple runs on the same scientific item and acquired measurements support both outputs. Our adaptive strategy estimates benchmarking and learning sample values separately, then selects which item to verify next. A lightweight learning operator updates external experimental memory while keeping the language model frozen. On held-out GB1 variant pairs, the memory improves the target agent's accuracy from 63.3% to 69.5%. At a matched 384-item budget, Adaptive Joint reaches 70.12% versus 69.27% for Random, but has higher benchmark mean-score error. The results support experimental-memory learning and identify a limitation of the current acquisition estimator.

Explicit Benchmarking Sample Value

The value of a candidate item is its marginal change to the current benchmark's run-aggregated discrimination score. It can be negative and is a selection proxy, not an exact reduction in mean-score MSE.

What The Analysis Establishes

Finite-run variability contributes to apparent agent separation. A single valid binary item has the same SNR under either non-tie winner, motivating a set-level marginal. Bounded sample values and feasible query accounting do not imply unbiased benchmark estimates, positive test gain or globally optimal selection.
